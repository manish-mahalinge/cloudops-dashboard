# CloudOps Dashboard

A DevOps and DevSecOps learning project demonstrating
containerization, CI/CD, GitOps, and Kubernetes deployment.

## Technology Stack

- Node.js
- Docker
- Kubernetes
- Jenkins
- SonarQube
- OWASP Dependency-Check
- Trivy
- Argo CD
- Prometheus
- Grafana

## Application Endpoints

| Endpoint | Purpose |
|----------|---------|
| `/` | Dashboard |
| `/health` | Basic application health response |

## Local Setup

Requirements:
- Node.js 22+

npm start
